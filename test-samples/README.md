# Test samples

Standalone HTML previews of real questions from the shared item pool
(`../platform/content/items.yaml`), for reviewing content quality and presentation
before finalizing the build plan.

These are **review artifacts, not the app** — open them directly in a browser. Each has a
"candidate view / review view" toggle: candidate view shows only the question and options
(what a test-taker sees); review view reveals the correct answer and worked explanation.

- `sample-01.html` — representative set: 4 numerical, 3 verbal, 4 logical.

We'll iterate on a few of these before locking the final look and content direction.
